تجهيز Kotlin على VS Code

دليل تفاعلي للطلاب على نظام Windows · إعداد: م. محمود أشرف أضهير
تقدّمك في التجهيز0 من 8

كيف تعمل الأدوات معاً؟

أربع أدوات، كل واحدة تسلّم عملها للتي بعدها عندما تضغط زر التشغيل:

VS Codeتكتب فيه الكود~100 MB
←
Code Runnerيرسل الكود للترجمة<1 MB
←
مترجم Kotlinيحوّله إلى برنامج~90 MB
←
Java (JDK)يشغّل البرنامج~190 MB

بعد التثبيت يعمل كل شيء على جهازك دون إنترنت.

قبل أن تبدأ

تأكّد من هذه الأمور:

  • جهاز يعمل بنظام Windows 10 أو 11.
  • مساحة فارغة لا تقل عن 1 جيجابايت.
  • ملفات التثبيت: من الإنترنت، أو من فلاشة المساق إذا كان الإنترنت ضعيفاً.
  • اتبع الخطوات بالترتيب، واضغط زر التأكيد بعد كل خطوة.
⏱ الوقت المتوقع: 30–45 دقيقة

واجهتك مشكلة؟

اكتب جزءاً مما يظهر أمامك، أو اختر نوع المشكلة، ثم افتحها لترى السبب والحل.

لا توجد مشكلة مطابقة. أرسل صورة واضحة للشاشة ورسالة الخطأ على مجموعة الواتساب الخاصة بالمساق.

مصطلحات ستقابلها

JDK
حزمة Java التي تحتوي على كل ما يلزم لتشغيل برامج Java و Kotlin.
المترجم (Compiler)
برنامج يحوّل الكود الذي تكتبه إلى برنامج يفهمه الحاسوب ويشغّله.
PATH
قائمة بالمجلدات التي يبحث فيها Windows عن الأوامر عندما تكتبها.
Terminal / Command Prompt
نافذة نكتب فيها الأوامر نصاً، وتظهر فيها نتيجة البرنامج.
إضافة (Extension)
برنامج صغير يضيف ميزة جديدة إلى VS Code، مثل زر التشغيل.
LTS
نسخة مستقرة تتلقى تحديثات لسنوات، وهي الأنسب للتعلّم.
